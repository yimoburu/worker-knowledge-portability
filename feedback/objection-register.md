# Objection Register

This register preserves substantive criticism, proposed governed-object
dispositions, and response status. An empty register means review has not yet
occurred; it does not imply consensus or endorsement.

| ID | Objection | Perspective | Governed object(s) | Proposed disposition(s) | Evidence | Proposed response | Charter change | Response status |
|---|---|---|---|---|---|---|---|---|

Name each governed object separately as a capability claim, evidence item, or
work artifact. If a proposed decision is relevant, use one of the four charter
dispositions for each object: **Retained in protected custody**, **Authorized
for specified use**, **Worker-portable claim**, or **Restricted or pending
dispute**. Do not assign one disposition to an entire person or case.

## Response status values

- **Open:** Recorded and awaiting response.
- **Investigating:** Evidence or stakeholder input is being gathered.
- **Accepted:** The objection changes the charter or project direction.
- **Partially accepted:** Part of the objection is addressed; remaining disagreement is recorded.
- **Not accepted:** The response and dissent remain public.
- **Superseded:** A later objection or charter change replaces this entry without deleting its history.
